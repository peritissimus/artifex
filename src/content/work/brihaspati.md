I led development of Brihaspati’s mobile application and backend as a founding engineer. The work spanned a Flutter app, Django and PostgreSQL services, and AWS infrastructure. The backend handled 100K+ daily requests with 99.9% uptime.

Personalization centered on dynamic prompting and context-aware memory retrieval. I worked on selecting relevant information for each generation so the content could reflect the person using the app. That work formed part of the broader personalization effort that helped improve D7 retention by 20%.

The engineering question was how to make that context useful within the limits of a production application. In [Scaling LLM Applications](/blog/scaling-llm-applications), I discuss the lessons from Brihaspati and Zoca: context budgets, retrieval, and measuring user outcomes alongside latency and cost.
